# Pages

Esta carpeta contiene las páginas principales del sistema.

Cada archivo representa una vista completa dentro de la aplicación.

## Estructura

pages/
- LoginPage.tsx
- RegisterPage.tsx
- ChatPage.tsx

---

## Páginas

### LoginPage.tsx
Pantalla principal de inicio de sesión.

Responsabilidades:
- mostrar formulario de acceso
- contener LoginForm
- gestionar autenticación inicial

---

### RegisterPage.tsx
Pantalla principal de registro.

Responsabilidades:
- mostrar formulario de registro
- contener RegisterForm
- gestionar creación de usuarios

---

### ChatPage.tsx
Pantalla principal del asistente conversacional.

Responsabilidades:
- mostrar interfaz del chat
- contener componentes conversacionales
- gestionar interacción con el asistente IA

Propósito:
ser la interfaz principal del usuario autenticado.
